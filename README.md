# Wine Tasting Bot 🍷

Telegram-бот для винного клуба «Tasting & Talk». Позволяет пользователям узнавать о предстоящих дегустациях, записываться на мероприятия, знакомиться с винами и оставлять отзывы.

## Функционал

### Пользовательский
- 🍷 Предстоящие дегустации — просмотр актуальных событий
- 📝 Запись на дегустацию — FSM-анкета с валидацией
- 🍇 Коллекция вин — подборка по мероприятиям
- 📸 Фото и отзывы — медиа-галерея
- ⭐ Оставить отзыв — ссылка на внешние ресурсы
- 📍 Контакты — адрес, соцсети, карта

### Административный
- 📅 Управление дегустациями (CRUD)
- 🍷 Управление винами (CRUD)
- 📸 Управление галереей (добавление/удаление фото)
- ⭐ Управление отзывами (CRUD)
- 📋 Просмотр заявок
- 📊 Статистика

### Интеграции
- Bitrix24 CRM — автоматическое создание лидов
- Уведомление менеджера в Telegram о новых заявках
- Контроль свободных мест
- Защита от дублей регистрации

## Быстрый старт

1. Клонировать репозиторий
2. Скопировать `.env.example` в `.env` и заполнить настройки
3. Установить зависимости: `pip install -r requirements.txt`
4. Запустить: `python -m app.main`

### Через Docker

```bash
docker compose -f docker/docker-compose.yml up -d
```
